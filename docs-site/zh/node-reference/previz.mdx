## 这个节点做什么

**3D 导演台**是一个预演(previz)控制台。往简易 3D 舞台上摆**演员** — 角色、马、车、狗,加上树、房子、岩石、墙、柱子、道具等布景 — 给会动的画**路径**,再定义**镜头(shot)**:每个镜头有自己的相机轨迹和时长,播完切下一个。按播放预览整场,然后**截帧**(每镜一张)或**录制**整条时间线成视频。

输出的定位是*参考,不是渲染成品*:录出的低模视频把相机轨迹、节奏、角色走位钉死,喂给参考生视频模型(作为 `@video_0`,配上定妆角色图);截帧则为逐镜出图钉死构图。

## 什么时候用

- 多镜头场景,要求运镜和走位跨条一致
- 给参考生视频工作流做运动参考(模型抄你的机位,控制权在你)
- 快速空间构思:追逐、对话、揭示,先想清楚再花 GPU

## ComfyTV 的设计

- **演员走轨道**:每个可动演员沿样条路径贯穿整条时间线,速度曲线可编辑;布景原地不动。挂载系统让角色骑马、上车。
- **镜头切换、世界连续**:shot 是带独立轨迹和时长的相机;切镜时世界继续演,像真实多机位拍摄。shot 可**锁定**某个演员,相机移动时始终framing 它。
- **太阳、地面、画幅**:太阳方向给可读的影子,地面样式可换,画幅预设在视口加黑边对齐交付格式。
- **一切进一个 widget**:整个场景(演员、路径、镜头、太阳、地面)序列化进 `previz_state`,随工作流保存复制。
- **Agent 可驱动**:[MCP 工具](https://github.com/jtydhr88/ComfyTV/blob/main/docs/mcp.zh.md) `previz_get` / `previz_edit` / `previz_capture` / `previz_record` 驱动同一个舞台,支持按坐标列表精确铺轨,还会对穿插的演员发警告。

## 参数

### width / height
截帧与录制分辨率(默认 1280×720)。

### 编辑器
工具栏加演员,拖拽落位,给可动的画路径;加 shot,塑形相机轨迹,设每镜时长,可选锁定主体;拖时间线或播放检查剪辑节奏。

## 输出

| 输出 | 类型 | 含义 | 下游 |
|---|---|---|---|
| **image** | `COMFYTV_IMAGE` | 最近截帧 | 图片工作流、参考 |
| **video** | `COMFYTV_VIDEO` | 录制序列 | 参考生视频工作流 |
| **images** | `COMFYTV_IMAGES` | 全部截帧 | 逐镜出图 |

## 一步步来

1. 添加 **3D 导演台**;不需要演示资产就先清场。
2. 摆演员和布景;给会动的画路径。
3. 每个机位加一个 shot;塑形轨迹、定时长,需要就锁定主体。
4. 播放,确认走位和切镜节奏。
5. **录制** → 把 **video** 作为 `@video_0` 连进参考生视频节点,配上定妆角色图(`@image_0`、`@image_1`)。
6. 视频 prompt 里写明哪个小人对应哪个角色,并强调**从第一帧起就是实拍质感** — 预演的低模外观绝不能漏进成片。

## FAQ

**Q:视频模型出片头一秒有棋盘格地面和灰色小人。**  
A:在 prompt 里写明参考只提供运镜和走位、输出从第一帧起完全实拍质感,并逐一指认哪个小人变成哪个角色。

**Q:和 Scene 3D 什么区别?**  
A:Scene 3D 是单机位质感台(布光、材质、动画 clip、四通道 capture);3D 导演台是多镜叙事走位 — 演员跑轨道、镜头切来切去。

**Q:序列能多长?**  
A:时间线长度=各镜时长之和,录制输出等长视频。参考片段贴近视频模型的分段长度,跟随度最好。

## 相关节点

- **Scene 3D** — 单镜质感与四通道 capture
- **Video Stage** — 消费录制的参考
- **导演台(Director)** — 把生成的各镜组装成片
